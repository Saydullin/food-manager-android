# Food Manager

**Русский | [English](README.md)**

Android-приложение в формате «Тиндер для еды» — свайпайте блюда, чтобы сформировать вкусовой профиль, и получайте персональные рекомендации на основе того, что вам понравилось.

## Возможности

- **Свайп-колода** — знакомство с блюдами по одному, в стиле Tinder
- **Персональные рекомендации** — лента «Для вас», построенная на истории свайпов
- **Избранное** — сохраняйте понравившиеся блюда и возвращайтесь к ним
- **Онбординг** — сбор начальных вкусовых предпочтений новых пользователей
- **Аутентификация по device-key** — вход без паролей
- **Управление профилем** — просмотр и редактирование вкусовых предпочтений

## Стек технологий

| Слой | Технология |
|---|---|
| UI | Jetpack Compose, Material 3 Expressive (alpha) |
| DI | Hilt |
| Асинхронность | Kotlin Coroutines & Flow |
| Локальное хранилище | Room 3, Preferences DataStore |
| Сеть | Retrofit, OkHttp, kotlinx.serialization |
| Загрузка изображений | Coil 3 |
| Навигация | Navigation Compose |
| Тестирование | JUnit, Turbine, MockK, Espresso |

Инструменты сборки: AGP 9 (со встроенным Kotlin 2.4), compileSdk/targetSdk 37, minSdk 29, JVM 11.

## Архитектура

Приложение построено по принципам **Clean Architecture** в мультимодульном Gradle-проекте. Зависимости направлены только внутрь/вниз — фичи зависят от core-модулей, но не наоборот, а core-модули более низкого уровня никогда не зависят от модулей более высокого уровня.

```
app                        — composition root, собирает фичи и навигацию

core/
├── model                  — чистые Kotlin-модели домена (сущности)
├── common                 — диспетчеры, типы Result, сквозные утилиты
├── domain                 — контракты репозиториев + use case'ы (без зависимостей от фреймворков)
├── designsystem           — тема Material 3 Expressive, токены, переиспользуемые UI-примитивы
├── ui                     — доменно-осведомлённые общие composable-компоненты (например, карточки блюд)
├── data                   — реализации репозиториев, координирующие источники ниже
├── database               — Room 3, локальный источник истины
├── network                — Retrofit + kotlinx.serialization, удалённый источник данных
├── datastore              — Preferences DataStore, вкусы/интересы пользователя
└── testing                — общие тестовые дублёры и утилиты

feature/
├── auth                   — регистрация и вход (device-key аутентификация)
├── onboarding              — сбор начальных вкусовых предпочтений
├── discover                — свайп-колода («Тиндер для еды»)
├── recommendations         — персональная лента «Для вас»
├── favorites                — понравившиеся / сохранённые блюда
├── details                 — экран деталей блюда (общий destination)
└── profile                  — профиль и управление вкусовыми предпочтениями
```

Каждый фичевый модуль внутри организован в собственные пакеты `domain` / `data` / `presentation`, повторяя тот же слой Clean Architecture в меньшем масштабе.

## Быстрый старт

### Требования

- Android Studio (с поддержкой AGP 9 / Kotlin 2.4)
- JDK 11+
- Android SDK с API 37

### Сборка и запуск

```bash
git clone https://github.com/Saydullin/food-manager-android.git
cd food-manager-android
./gradlew assembleDebug
```

Либо откройте проект в Android Studio и запустите конфигурацию `app` на устройстве/эмуляторе с API 29+.

### Полезные Gradle-задачи

```bash
./gradlew test              # юнит-тесты по всем модулям
./gradlew connectedCheck    # инструментальные тесты
./gradlew assembleRelease   # release APK
```
